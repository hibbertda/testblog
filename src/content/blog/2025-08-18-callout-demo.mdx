# Callout Component Showcase

This demo post showcases the new reusable callout component that can be used in MDX blog posts. Here are all the different types available:

## Basic Callouts

<Callout type="note">
This is a **note** callout. Perfect for highlighting important information that readers should pay attention to. You can include [links](https://example.com) and **formatted text** inside callouts.
</Callout>

<Callout type="info">
This is an **info** callout. Similar to note but semantically different. Use this for general information that might be helpful but not critical.
</Callout>

<Callout type="tip">
This is a **tip** callout. Great for sharing helpful advice, best practices, or pro tips that can improve the reader's experience or workflow.
</Callout>

<Callout type="warning">
This is a **warning** callout. Use this when you need to alert readers about potential issues, deprecated features, or things they should be careful about.
</Callout>

<Callout type="error">
This is an **error** callout. Reserved for critical information about things that are broken, dangerous, or will cause problems if not addressed.
</Callout>

## Code Integration

Callouts work great alongside code blocks:

```bash
# Create a new resource group
az group create --name demo-rg --location eastus
```

<Callout type="tip">
The `eastus` location is often a good default choice for demos because it typically has the most Azure services available and competitive pricing.
</Callout>

<Callout type="note" title="Code in Callouts">
You can include code blocks directly inside callouts:

```json
{
  "name": "demo-app",
  "version": "1.0.0",
  "dependencies": {
    "express": "^4.18.0"
  }
}
```

Or inline code like `npm install` and `az login` commands.
</Callout>

<Callout type="warning" title="PowerShell Example">
Be careful when running destructive commands:

```powershell
# This will delete ALL resources in the resource group!
Remove-AzResourceGroup -Name "demo-rg" -Force
```

Always double-check your resource group name before running deletion commands.
</Callout>
